因为有 n+1 个数，数字都在 `[1,n]` 之间，所以每个值都可以作为合法的索引。
如果存在重复数字，说明有多个节点指向同一个位置，这在图中必然会形成一个环。
重复的那个数字，就是环的入口。
```python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = nums[0]
        fast = nums[nums[0]]
        
        while slow != fast:
            slow = nums[slow]
            fast = nums[nums[fast]]
        
        slow = 0
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
            
        return slow
```
