既然多数元素的个数大于一半，那么让它和其他元素一对一抵消，最后剩下的那个一定就是多数元素。
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        candidate = None
        count = 0
        
        for num in nums:
            if count == 0:
                candidate = num
            
            if num == candidate:
                count += 1
            else:
                count -= 1
                
        return candidate
```
