# DFS
Python 的 len(list)复杂度是 O 1！😨因为他自己维护了 size 属性！
所以不需要设置全局变量记录长度，自己搞的还容易不一致
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        self.results = []
        self.max_height = 0 # len and first empty layer
        def traverse(root, layer):
            if not root:
                return None
            if layer == self.max_height:
                self.results.append(root.val)
                self.max_height += 1
            traverse(root.right, layer + 1)
            traverse(root.left, layer + 1)
            return None
        traverse(root, 0)
        return self.results

```


| 操作                    | 复杂度        |                   |
| --------------------- | ---------- | ----------------- |
| `len(list)`           | $O(1)$     | 内部维护了长度属性         |
| `if item in list:`    | $O(n)$     | 遍历列表              |
| `list = list + [val]` | $O(n + m)$ | 创建新列表，拷贝元素        |
| `list.append(val)`    | $O(1)$     | 原地                |
| `list.extend([val])`  | $O(1)$     | 原地                |
| `list += [val]`       | $O(1)$     | 原地（调用 extend）     |
| `list.insert(0, val)` | $O(n)$     | 原地但是后面所有元素都要往后挪一位 |
| `list.pop()`          | $O(1)$     | 原地，其他元素不动         |
| `list.pop(0)`         | $O(n)$     | 原地但是后面所有元素都要往前挪一位 |
