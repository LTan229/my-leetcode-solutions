```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        leftprod = [1]
        rightprod = [1]
        n = len(nums)
        lefttemp, righttemp = 1, 1
        for i in range(n):
            lefttemp *= nums[i]
            righttemp *= nums[n - i - 1]
            leftprod.append(lefttemp)
            rightprod.append(righttemp)
        results = []
        for i in range(n):
            results.append(leftprod[i] * rightprod[n - i - 1])
        return results
```

空间优化：先用输出数组存储前缀积。然后从右往左遍历，用一个变量实时记录后缀积，并直接乘到输出数组里。
